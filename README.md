# Gomuko-1 (C++, multiplayer)

Multiplayer Gomoku (five in a row) in the C++ console.

## How to play

You enter the board size, the number of players and the win length. Players take turns placing a symbol, and the first to connect the win length in a row wins.

## Requirements

Windows, because the game uses `windows.h` and `conio.h`.

## Build

Open `gomuko2.sln` in Visual Studio and run it. You can also compile `gomuko2.cpp` with any C++ compiler that supports these headers.
